# Sleep Protocol — Nightmare Simulator 💀

A full-stack AI-powered psychological horror experience.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js installed
- MongoDB Atlas account (or local MongoDB)
- OpenAI API Key

### 2. Backend Setup
1. Navigate to `server/`
2. Create a `.env` file (copy `.env.example`)
3. Add your `MONGO_URI` and `OPENAI_API_KEY`
4. Run:
   ```bash
   npm install
   npm run dev
   ```

### 3. Frontend Setup
1. Navigate to `client/`
2. Run:
   ```bash
   npm install
   npm run dev
   ```

## 🎮 Experience Features
- **Glitch UI**: Immersive VHS aesthetics and CRT flicker.
- **AI Nightmare Engine**: Generates unique horror stories based on your fears.
- **Neural Corruption**: Real-time fractal backgrounds and ambient whispers.
- **Echoes of Trauma**: Browse previous nightmares stored in the void (MongoDB).

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Three.js, Howler.js
- **Backend**: Node.js, Express, MongoDB, OpenAI API
